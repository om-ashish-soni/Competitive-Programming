## Why headless-twitter?

In an era where Twitter API costs are skyrocketing ($100+/mo for basic access), `headless-twitter` provides a lightweight, secure, and **free** way to read your feed, search tweets, and monitor accounts directly from your terminal.

It connects to your **logged-in Chrome** via CDP (Chrome DevTools Protocol). Intercepts Twitter's internal GraphQL responses directly. No API keys. No DOM scraping. No Selenium. No Playwright download. Just your Chrome + one command.

## The "Hacker" Experience

```bash
# Search tweets about 'rust lang'
headless-twitter twitter search "rust lang" 15 --lang en
```
